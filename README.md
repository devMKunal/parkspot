# ParkSpot

Find and pre-book parking in busy areas, with Google Maps discovery and Razorpay payments that are created and verified on the server.

| Folder | What | Status |
|---|---|---|
| [`api/`](api) | Node.js + TypeScript + Express + MongoDB REST API | Auth, nearby lots, bookings, payments |
| [`app/`](app) | Flutter client (BLoC, clean architecture) | Not started |
| [`docs/`](docs) | Design docs | [Auth API](docs/auth-api.md), [Lots API](docs/lots-api.md), [Bookings API](docs/bookings-api.md), [Payments](docs/payments-api.md) |

Demo video, architecture diagram and APK link land here at Milestone 7.
