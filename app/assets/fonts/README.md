# Fonts

Static TTFs downloaded from Google Fonts and bundled, so the app never fetches fonts at runtime.

| Family | Weights | Role | License |
|---|---|---|---|
| [Bricolage Grotesque](https://fonts.google.com/specimen/Bricolage+Grotesque) | 600, 700, 800 | display, headline, titleLarge, buttons | SIL Open Font License 1.1 |
| [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) | 400, 500, 600, 700 | body, labels, fields | SIL Open Font License 1.1 |

The OFL lets us bundle and ship these fonts in the app. Each family's license text is on its Google Fonts page under "License".
